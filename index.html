01

Разберёмся, нужен ли вам ключ

Для чего он нужен

OpenAI API key — секретный ключ, который позволяет вашему приложению обращаться к моделям OpenAI. Он нужен, когда бот должен генерировать ответы с помощью OpenAI. Для обычного бота с заранее заданными кнопками и ответами он не обязателен.

Не путайте два ключа: токен BotFather подключает бота к Telegram; OpenAI API key подключает программу бота к моделям OpenAI. Это разные секреты.

03

Открываем платформу OpenAI

Начинаем с официального сайта

  1. Нажмите кнопку ниже и откройте platform.openai.com.
  2. Нажмите Sign up для регистрации или Log in для входа. Можно использовать свой существующий аккаунт OpenAI, если он доступен для API.
  3. Выполните шаги, которые покажет платформа: подтверждение электронной почты и другие требуемые действия.
  4. После входа проверьте, что выбран нужный аккаунт и организация. Если интерфейс отличается, ориентируйтесь на названия разделов.

04

Знакомимся с оплатой API

ChatGPT и API оплачиваются отдельно

Подписка ChatGPT Plus сама по себе не оплачивает запросы вашего бота к API. Расход зависит от модели, количества входных и выходных токенов и используемых функций. Для некоторых подходящих подписок или аккаунтов могут быть доступны отдельные кредиты — проверяйте свой баланс в панели.

  1. В панели OpenAI откройте Settings → Billing или страницу оплаты по кнопке ниже.
  2. Посмотрите доступные способы оплаты и условия в вашем аккаунте. Для платного использования добавьте доступный платёжный метод и при необходимости приобретите кредиты.
  3. Перед подтверждением проверьте сумму, срок действия кредитов и условия. Новые API-аккаунты используют предоплату; приобретённые кредиты обычно действуют год.
  4. Проверьте настройки Auto recharge: включайте автопополнение только осознанно, предварительно изучив порог и лимит покупок.

05

Выбираем проект и создаём ключ

Один проект — удобный способ отделить расходы бота

  1. Откройте API keys по кнопке ниже или через настройки организации и выбранного проекта.
  2. Выберите существующий проект. Если у вас есть права владельца организации, можно создать отдельный проект для бота и выбрать его.
  3. Нажмите + Create new secret key.
  4. Укажите понятное название, например telegram-bot, и проверьте выбранный проект. При доступности ограниченных разрешений дайте ключу только необходимые права для используемого API.
  5. Нажмите Create secret key. Скопируйте ключ и сохраните в менеджере паролей: полностью он показывается при создании.
Не отправляйте ключ в чат, ученицам или в Cursor. Не показывайте экран с ним во время записи. Потерянный ключ нужно создать заново.

06

Подключаем ключ к боту

Cursor подготовит проект — секрет вставляете только вы

  1. Откройте папку бота в Cursor. Скопируйте запрос ниже в чат Cursor без значения ключа.
  2. Проверьте предложенные изменения и попросите Cursor назвать точное имя переменной и файл локальных настроек для вашего проекта. Часто используют OPENAI_API_KEY, но важно следовать настройкам проекта.
  3. Откройте локальный файл настроек, указанный Cursor, и самостоятельно вставьте значение ключа в нужную переменную. Не отправляйте содержимое файла в чат ИИ.
  4. Проверьте, что файл с секретами исключён через .gitignore и не отображается среди отправляемых изменений в GitHub Desktop.
  5. Остановите и снова запустите локального бота привычным для вас способом, затем проверьте ответ в Telegram.
Изучи мой проект Telegram-бота и помоги безопасно подключить OpenAI API для ответа на сообщения. Не меняй другие функции бота без необходимости. Используй подходящую доступную модель и сообщи её название, объясни, от чего зависит стоимость. Читай API-ключ только из переменной окружения и не записывай его значение в код, репозиторий или журналы. Подготовь необходимые настройки для локальной работы и для Timeweb Cloud App Platform. Проверь .gitignore и исключение файлов с секретами. Объясни простыми словами, куда я сама должна вставить ключ, какое точное имя у переменной и как проверить работу. Не проси присылать значение ключа, не используй терминал и не проси меня вводить команды.

Если ключ уже был опубликован или показан посторонним, отзовите его в API keys, создайте новый и замените его во всех настройках.
07

Добавляем ключ на Timeweb Cloud

Для бота, который уже размещён на сервере

  1. В Timeweb Cloud откройте App Platform → ваше приложение → Настройки.
  2. Найдите «Настройка деплоя» → «Редактировать» и раздел «Переменные». Добавьте переменную с точным именем из вашего проекта — например OPENAI_API_KEY.
  3. Вставьте ключ в поле значения и сохраните настройки. Токен Telegram остаётся отдельной переменной.
  4. Отправьте подготовленные изменения проекта через GitHub Desktop: Commit, затем Push origin. Если автодеплой выключен, запустите деплой вручную; после изменения переменных убедитесь, что выполнен новый запуск приложения.
  5. Дождитесь запуска и проверьте бота в Telegram. Локальную копию бота с polling предварительно остановите.
Для локального запуска ключ хранится в локальных настройках; для серверного — отдельно в переменных Timeweb. Не размещайте его в GitHub.

08

Проверяем расходы и результат

Держим использование под контролем

  1. Отправьте боту простой вопрос, на который он должен ответить с помощью ИИ. Убедитесь, что ответ соответствует задаче.
  2. Откройте Usage, выберите нужный период и проект. Данные могут появиться не сразу; доступ к панели зависит от прав аккаунта.
  3. В настройках организации и проекта проверьте доступные ограничения расходов и уведомления. Уведомление о бюджете само по себе может не останавливать запросы; используйте жёсткий лимит, если он доступен, и учитывайте задержки учёта.
  4. Если бот не отвечает, проверьте логи без публикации секретов, баланс, проект, имя переменной и доступность модели. Ошибка 429 может означать ограничение частоты, исчерпание баланса или лимит расходов.

Частые вопросы

Это тот же ключ, что выдаёт BotFather?

Нет. BotFather выдаёт токен Telegram-бота. OpenAI API key нужен, чтобы программа обращалась к моделям OpenAI. Оба значения секретные.

У меня есть ChatGPT Plus. API будет бесплатным?

Подписка ChatGPT Plus и API оплачиваются отдельно. Проверьте баланс и условия вашей организации в API Billing.

Ключ потерялся или попал в открытый доступ

Отзовите его на странице API keys, создайте новый и обновите настройки на компьютере и сервере. Проверьте использование и обратитесь в поддержку при подозрительной активности.

Почему ошибка 429?

Причина может быть в исчерпанном балансе, лимите расходов или слишком частых запросах. Проверьте текст ошибки, Billing, лимиты и Usage. Не показывайте секреты на скриншотах.

Нужно ли всем ботам подключать OpenAI?

Нет. Если бот работает по заранее заданному сценарию и кнопкам, ключ OpenAI не обязателен.
